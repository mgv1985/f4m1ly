# Floral Gallery

To add a photograph:

1. Copy it into the matching folder under `images/`.
2. Open `gallery-data.js`.
3. Add `['images/Folder/filename.jpg', 'Name shown in the gallery']` to that category's `images` list.

For Roses, add the line inside the `red`, `white`, or `colors` group. Paths and titles are the only gallery data that need editing.
